Discord iOS Widget

Designing a native iOS widget for Discord — bringing key social features to the home screen without opening the app.

Overview

Closing the gap on iOS widget engagement

With the current industry push for iOS products to include widgets, Discord is missing out on a share of user engagement and staying on trend with other social media apps. Widgets improve overall app functionality and save users time — giving them instant access to key features without opening the app.

With over 150 million active monthly users, Discord has primarily targeted adults and gamers and has become a core social media choice since launching in 2015. This project explores what a thoughtful Discord widget could look like.

Process

Research, features, and iOS guidelines

Widgets by design need to be concise, summarising the core features of an app by providing instant access to meaningful content. Content and function are consistent across iOS widget sizes, though different visualisations are used depending on size selected.

Along with information architecture mapping, product research, and user interviews, the key features selected for a Discord widget were:

Account activity status Friends list access Search functionality Direct message notifications Server-wide notifications

Defining the widget's features allows content to be shared dynamically throughout the day, keeping it relevant and maintaining a prominent position on a user's device.

Design

From sketches to high-fidelity

Research and user data concluded that widgets need variety in available designs, even within the same size. Variety allows users to customise and personalise the widget better for their needs.

Using the current iOS component library for sizing and UI specifications, the ideation process moved from sketches to low-fidelity wireframes. User journeys were mapped to different widget designs and refined further through testing.

Outcome

A handover-ready, customisable design

Utilising Discord's branding guidelines, dark and light mode high-fidelity prototypes were built after running user and heuristic testing. Users can pick between several options to best suit their device and customise the focus of the widget design.

Due to the highly customisable elements of the design, an annotated design file and template was prepared for handover, making it straightforward for engineers to implement.
